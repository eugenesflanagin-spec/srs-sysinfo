# SRS 1.1.0 - User guide, Guide links and redacted reports

I wanted a Linux version of SIV (System Information Viewer) for myself, so I built one and set out to
improve on it along the way. SRS is free and open source for the Linux and open-source community.
(SRS is an independent project, not affiliated with SIV or its author.)

## Highlights

- **A full user guide, built in.** A 462-page guide (PDF + HTML) explains every window, option and
  command, and all 545 items in plain words: what you see, what's normal, what's unusual and where
  Linux gets it. New menu entry **SRS User Guide (PDF)**.
- **Guide links on every page.** Press **F1**, click **Guide**, or right-click → "Open guide for this
  item" to jump straight to that item's section. Works offline. Command line: `sysreport-search guide ITEM`.
- **Safe-to-share reports.** `-save ... --redact` (or Options → "Redact identifiers in saved reports")
  masks serial numbers, UUIDs, machine/boot IDs and the host name, so you can post a report in a forum.
- **Works on more PCs out of the box.** Several items now check your actual hardware (fan-control
  program, GPU LEDs, Thunderbolt/USB4, sensor inputs, cache sizes, Intel hybrid E-cores).
- **DDR5 memory details** now show even when `decode-dimms` can't read DDR5 (falls back to SMBIOS).
- Many smaller fixes across AMD SMU, ACPI tables, device names, storage, network, desktop
  "battery" detection and benchmarks. Full list in [CHANGELOG.md](CHANGELOG.md).

## Install

**Arch Linux**

```sh
sudo pacman -U srs-sysinfo-1.1.0-1-x86_64.pkg.tar.zst
# or from the AUR:  yay -S srs-sysinfo
```

**Debian / Ubuntu**

```sh
sudo apt install ./srs-sysinfo_1.1.0-1.deb13_amd64.deb        # or the .ubuntu24.04 file
```

**Fedora / openSUSE**

```sh
sudo dnf install ./srs-sysinfo-1.1.0-1.fc44.x86_64.rpm
sudo zypper install ./srs-sysinfo-1.1.0-1.tw.x86_64.rpm
```

**Any other distribution**

```sh
tar xf srs-sysinfo-1.1.0-linux-x86_64.tar.gz
cd srs-sysinfo-1.1.0-linux-x86_64
./usr/bin/srs-gui                     # run in place, or install:
sudo cp -r usr/bin usr/share /usr/local/
```

`INSTALL.txt` in the tarball covers the optional boot-time service and uninstalling.

## Requirements

- 64-bit x86 Linux. Use the package for your distro; the generic `linux-x86_64.tar.gz` is built from the
  Arch package and needs glibc 2.42 or newer (check with `ldd --version`)
- GTK 3, GLib, Pango, Cairo, and `hwdata`
- Optional, for more detail: polkit (for `srs-root`), dmidecode, smartmontools, nvme-cli, i2c-tools,
  pciutils, usbutils, lm-sensors, vulkan-tools, clinfo, mesa-utils, libayatana-appindicator (tray icon)
- For guide links at the exact page: Okular, Evince or Papers (other viewers open the HTML guide)

## Upgrading from 1.0.x

Nothing to do: settings, the boot-time service and benchmark settings carry over.
