# SRS 1.1.1 - Burn-in results saved, GPU rolling average fixed, SMT worked example

A small update to 1.1.0.

## What's new

- **Fixed: GPU Frequency "Rolling Average" showed 0 MHz** in the CPU Burnin / CPU Stress window,
  while the current clock was 2400-3000 MHz. The GPU clock was never added to the rolling average.
  The other rows (CPU load, CPU clock, temperatures, GPU load) were already right.
- **Burn-in results are saved.** Every CPU Burnin or CPU Stress run that ends (Pass, Fail or Stopped)
  is kept in its own file, `~/.cache/srs/burnin-YYYYMMDD-HHMMSS.txt`, with the same text as the Copy
  button: status, the sensor table and the per-thread table. Compare two runs, for example before
  and after a BIOS change, with `diff` or `meld`. The command line `sysreport-search burn` saves
  its summary the same way.
- **New guide page: "What hyperthreading (SMT) really does - a worked example"** (User Guide 9.2.1).
  One Ryzen 7 7800X3D's benchmark results, explained step by step: the two threads of a core are
  equally fast, an all-core run scores about 5 % lower because of boost, the second thread adds
  66-80 % more work, and mixed integer + floating-point work shares a core better than identical work.
- `--version` now shows the project's home page.
- The generic tarball now runs on older distributions: it needs glibc 2.38 or newer (1.1.0's needed 2.42).

Full list in [CHANGELOG.md](CHANGELOG.md).

## Install

**Arch Linux**

```sh
sudo pacman -U srs-sysinfo-1.1.1-1-x86_64.pkg.tar.zst
# or from the AUR:  yay -S srs-sysinfo
```

**Debian / Ubuntu**

```sh
sudo apt install ./srs-sysinfo_1.1.1-1.deb13_amd64.deb        # or the .ubuntu24.04 file
```

**Fedora / openSUSE**

```sh
sudo dnf install ./srs-sysinfo-1.1.1-1.fc44.x86_64.rpm
sudo zypper install ./srs-sysinfo-1.1.1-1.tw.x86_64.rpm
```

**Any other distribution**

```sh
tar xf srs-sysinfo-1.1.1-linux-x86_64.tar.gz
cd srs-sysinfo-1.1.1-linux-x86_64
./usr/bin/srs-gui                     # run in place, or install:
sudo cp -r usr/bin usr/share /usr/local/
```

`INSTALL.txt` in the tarball covers the optional boot-time service and uninstalling.

## Requirements

- 64-bit x86 Linux. Use the package for your distro; the generic `linux-x86_64.tar.gz` is built from the
  Ubuntu 24.04 package and needs glibc 2.38 or newer (check with `ldd --version`)
- GTK 3, GLib, Pango, Cairo, and `hwdata`
- Optional, for more detail: polkit (for `srs-root`), dmidecode, smartmontools, nvme-cli, i2c-tools,
  pciutils, usbutils, lm-sensors, vulkan-tools, clinfo, mesa-utils, libayatana-appindicator (tray icon)
- For guide links at the exact page: Okular, Evince or Papers (other viewers open the HTML guide)

## Upgrading from 1.1.0

Nothing to do: settings, the boot-time service and saved benchmark results carry over.
