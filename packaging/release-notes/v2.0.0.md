# SRS 2.0 - a new main window

SRS gets a friendlier main window. Everything SRS showed before is still there, one click away, and
the classic SIV-style windows are still available.

## What's new

- **One window with a sidebar of pages**: Overview, Processor, Memory, Motherboard & BIOS,
  Graphics & audio, Storage, Network, Sensors, USB & PCI devices, Operating system, Benchmarks &
  stress, and Tools. It follows your desktop's light or dark theme.
- **"Is my PC OK?"** on the Overview: a status light for CPU and graphics temperature, drive health
  (SMART) and temperature, hardware errors, free disk space, memory in use and sensor alarms, each
  explained in plain words, with a **Details** button that shows the readings behind it. Temperatures
  are judged against each sensor's own limit (the CPU's maximum, the card's critical hotspot
  temperature, each drive's warning temperature). Cards below give the key numbers for the
  processor, graphics, memory, storage, operating system and motherboard.
- **Every page** starts with a short explanation and the key facts, then the same detailed panels
  as before as tabs: same text, colours and live updates, with Refresh, Copy, Guide (F1) and
  **Open in window**. **All N items** on each page lists every item, the expert ones included.
- **Search** in the title bar (Ctrl+F): type "temperature", "SMART", "BIOS"... and pick an item, or
  press Enter to find text on the current tab.
- **Classic view**: Menu -> Classic View, the button under the sidebar, or `srs-gui --gui-classic`.
  **Options -> Start in classic view** makes it the default; `--gui-new` opens the new window anyway.
- **Clearer names**: the "Windows (OS) panel" is now **General Info**, and "About SIV" is now
  **About SRS**, which starts with who made SRS, its licence and its home page. Their IDs
  (`windows`, `about`) are unchanged.

Existing commands, options and item IDs are unchanged (`srs-gui` gains two start options, `--gui-classic`
and `--gui-new`); saved reports only show the two new names. The **Redact** option works as before for
Save Report, the Copy button and right-click Copy / Ctrl+C.

The user guide has a new tour of the main window with screenshots, and every section of it says where
to find things in the new window and in the classic view.

Full list in [CHANGELOG.md](CHANGELOG.md).

## Install

**Arch Linux**

```sh
sudo pacman -U srs-sysinfo-2.0.0-1-x86_64.pkg.tar.zst
# or from the AUR:  yay -S srs-sysinfo
```

**Debian / Ubuntu**

```sh
sudo apt install ./srs-sysinfo_2.0.0-1.deb13_amd64.deb        # or the .ubuntu24.04 file
```

**Fedora / openSUSE**

```sh
sudo dnf install ./srs-sysinfo-2.0.0-1.fc44.x86_64.rpm
sudo zypper install ./srs-sysinfo-2.0.0-1.tw.x86_64.rpm
```

**Any other distribution**

```sh
tar xf srs-sysinfo-2.0.0-linux-x86_64.tar.gz
cd srs-sysinfo-2.0.0-linux-x86_64
./usr/bin/srs-gui                     # run in place, or install:
sudo cp -r usr/bin usr/share /usr/local/
```

`INSTALL.txt` in the tarball covers the optional boot-time service and uninstalling.

**AppImage (any distribution)**

```sh
chmod +x srs-sysinfo-2.0.0-x86_64.AppImage
./srs-sysinfo-2.0.0-x86_64.AppImage
```

With arguments it is the command line (`--version`, `find ...`, `srs-sysreport`). Run as root
works from it; the boot-time refresh needs the package for your distro. AppImageUpdate (or a
manager that uses it, such as AppImageLauncher) keeps it up to date.

## Requirements

- 64-bit x86 Linux. Use the package for your distro; the generic `linux-x86_64.tar.gz` is built from the
  Ubuntu 24.04 package and needs glibc 2.38 or newer (check with `ldd --version`)
- GTK 3, GLib, Pango, Cairo, and `hwdata`
- Optional, for more detail: polkit (for `srs-root`), dmidecode, smartmontools, nvme-cli, i2c-tools,
  pciutils, usbutils, lm-sensors, vulkan-tools, clinfo, mesa-utils, libayatana-appindicator (tray icon)
- For guide links at the exact page: Okular, Evince or Papers (other viewers open the HTML guide)

## Upgrading from 1.1.x

Nothing to do: settings, the boot-time service and saved benchmark results carry over. If you prefer
the old layout, tick **Options -> Start in classic view**.
