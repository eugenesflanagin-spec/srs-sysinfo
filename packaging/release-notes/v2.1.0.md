# SRS 2.1 - tabs your way, sortable tables, a Startup manager

SRS 2.1 lets you arrange the main window the way you like it, sort any table, and manage what
starts with your PC. Everything from 2.0 is still there, and the classic SIV-style windows too.

## What's new

- **Tabs you can arrange**: add a tab with **+** (Ctrl+T), close, replace (right-click > Replace
  with...), drag and keep tabs. SRS remembers each page's tabs and their order. Items you open just
  to look at are temporary until you keep them.
- **All N items** is now a searchable jump list: type a few letters and pick the item.
- **Your choice of tabs and tab bar**: per page the standard tabs, the ones you tick, or every item
  (or every item on all pages at once), shown in one scrolling row, wrapped rows or a side list.
- **Lineups**: Basic, Enthusiast (the default) and Expert are built in; save your own, then
  export and import them. Change things on the fly and save only if you want to.
- **Less clutter**: items that cannot show anything on your PC (Windows-only, hardware that is not
  there, empty results) are hidden; **Options -> Show hidden items** lists them.
- **Sortable tables**: click a column heading (▲ then ▼). Sizes, clocks, temperatures, fan speeds
  and dates sort by value. **Reset view** puts the original order back; reports and Copy keep it.
- **Startup manager** (Operating system -> Startup programs): switch autostart entries and
  services off and on without deleting anything, with Undo, Restore default and **Add to
  startup...** (a program or a command, with an optional delay). It asks before touching parts of
  the desktop or system services.
- **Full access / Limited badge** in the title bar, with a **Run as root...** button when root data
  is missing.
- **CPU Clocks: stock and in effect now**: the measured base clock (BCLK or AM5 eCLK), core base,
  boost and current clock at stock and in effect, and FCLK, UCLK and MCLK from the SMU.

Existing commands, options, item IDs and report formats are unchanged; the CPU Clocks item gains
its new table in reports too. Settings carry over from 2.0.

The user guide has new sections on arranging tabs and lineups, sortable tables, the Startup
manager and the badge.

## Install

**Arch Linux**

```sh
sudo pacman -U srs-sysinfo-2.1.0-1-x86_64.pkg.tar.zst
# or from the AUR:  yay -S srs-sysinfo
```

**Debian / Ubuntu**

```sh
sudo apt install ./srs-sysinfo_2.1.0-1.deb13_amd64.deb        # or the .ubuntu24.04 file
```

**Fedora / openSUSE**

```sh
sudo dnf install ./srs-sysinfo-2.1.0-1.fc44.x86_64.rpm
sudo zypper install ./srs-sysinfo-2.1.0-1.tw.x86_64.rpm
```

**Any other distribution**

```sh
tar xf srs-sysinfo-2.1.0-linux-x86_64.tar.gz
cd srs-sysinfo-2.1.0-linux-x86_64
./usr/bin/srs-gui                     # run in place, or install:
sudo cp -r usr/bin usr/share /usr/local/
```

`INSTALL.txt` in the tarball covers the optional boot-time service and uninstalling.

**AppImage (any distribution)**

```sh
chmod +x srs-sysinfo-2.1.0-x86_64.AppImage
./srs-sysinfo-2.1.0-x86_64.AppImage
```

With arguments it is the command line (`--version`, `find ...`, `srs-sysreport`). Run as root
works from it; the boot-time refresh needs the package for your distro. AppImageUpdate (or a
manager that uses it, such as AppImageLauncher) keeps it up to date.

## Requirements

- 64-bit x86 Linux. Use the package for your distro; the generic `linux-x86_64.tar.gz` is built from the
  Ubuntu 24.04 package and needs glibc 2.38 or newer (check with `ldd --version`)
- GTK 3, GLib, Pango, Cairo, and `hwdata`
- Optional, for more detail: polkit (for `srs-root`), dmidecode, smartmontools, nvme-cli, i2c-tools,
  pciutils, usbutils, lm-sensors, vulkan-tools, clinfo, mesa-utils, libayatana-appindicator (tray icon)
- For guide links at the exact page: Okular, Evince or Papers (other viewers open the HTML guide)

## Upgrading from 2.0

Nothing to do: your settings carry over and the main window opens with the standard tabs (the
Enthusiast lineup). If you liked 2.0's plain-text tables, untick **Options -> Sortable tables**.
