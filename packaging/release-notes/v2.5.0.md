# SRS 2.5.0 - The Big Top, live tray meters and an IR Blaster

An update to SRS 2.4. Everything from 2.4 is still there, and your settings, tabs and lineups carry
over. 2.4.1 was never released on its own; its changes (benchmark times up to 60 s, a Cache & Memory
fix) are part of this release.

## What's new

- **The Big Top** (Ctrl+G, or the button next to the search box): a live window for the whole PC
  and each graphics card.
  - Its **Performance** tab works like a task manager:
    - **Summary** and **Performance**: live meters and graphs for the CPU, memory, CPU power,
      temperatures, every disk, network adapter and GPU.
    - **Processes**: End Task, Force Kill, End Process Tree, Suspend / Resume, Priority, CPU
      Affinity and Properties. It always asks first, never touches PID 1 or kernel threads, and asks
      for a password (polkit) before acting on another user's process. A zombie process is explained
      in plain words, with End Parent Process.
    - **Startup Apps**: everything that starts at login, one-click on / off, Add, Remove to a
      trash you can restore from, Restore Default, and an Undo that survives a restart. It never
      writes to `/etc`.
    - **Users** (sessions, Disconnect), **Services** (Start / Stop / Restart, asks first) and
      **Run New Task**.
  - Its **GPU tabs** are a C reimplementation of amdgpu_top by Umio Yasuno (MIT) for AMD cards,
    with NVIDIA cards through NVML. They show busy engines, video memory, which programs use the
    card, clocks, power, temperatures, every gpu_metrics field, an SMI table of all cards, the
    display connectors, the PowerPlay table and the XDNA NPU.
  - Everything in the GPU tabs is read-only.
  - A card that can sleep is left asleep while it is idle.
  - The GRBM performance counters are off by default; turn them on when you need the GRBM panels.
  - The window starts on the first awake card and wakes a sleeping one only when you pick it.
  - On the command line: `sysreport-search gpu-top` (or `big-top`). It reads the GRBM counters only
    with `--pc`, and opens a sleeping card only with `--device N --wake`.
- **Live tray meters, off by default.** CPU, cores, CPU temperature, memory, GPU busy /
  temperature / video memory, disk and network can each be their own updating icon in the
  notification area, even while SRS is hidden.
  - Turn them on in **Menu -> Options -> Customize Task Manager (Performance tab, tray meters)... ->
    Live Telemetry Icons**.
  - The same dialog sets the update speed, keep running in the tray, start minimised at login and a
    summon shortcut.
  - The SRS icons stay together, in the order of the settings. **Tray Position** puts them with the
    hardware icons (Normal) or first in the tray. The desktop still decides the final order.
  - On Plasma, if they hide under the tray arrow: right-click the arrow > Configure System Tray >
    Entries > Always shown.
  - `srs-gui --tray` starts with only the tray icons.
- **IR Blaster** (USB & PCI devices page; `sysreport-search ir`): use an ELK Smart / OCRUSTAR USB
  infrared dongle as a remote control.
  - Learn a button from your TV remote, name it, and send it again (with Repeat, or Dry Run to see
    the USB packets only).
  - Type in a code, and import or export your codes.
  - The codes are shared with the IR Remote app.
  - The tab is greyed while no dongle is plugged in, and shows the udev rule (with a Copy Install
    Command button) when access is missing.
- **One startup manager.** Operating system -> Startup programs -> Manage now opens Startup Apps.
  The old 2.2 Startup manager is gone; Startup Apps has its Restore Default, and its Restore Removed
  brings back the copies the old manager saved.
- **All Cores (Max)** (Alt+X) beside Threads on the CPU benchmarks and on Stress & Burnin: every
  logical CPU for one run, without changing a saved setting. On Crypto, CPU Compute and Everyday Work it runs only
  the all-threads pass (the 1-thread cells say "skipped"; about half the time). Command line: `--all-threads-only`.
- **Benchmark times up to 60 s** on every benchmark, in the window and on the command line.
- **One load at a time.** While a benchmark or Stress & Burnin runs, the other pages' Run / Start buttons are greyed
  (the tooltip names the running test); a lock file also warns when another SRS window or `sysreport-search` is running one.
- **Stop on every benchmark page** (CPU Benchmark, IPI Delay, Latency and Crypto too) and **Run All** on Everyday Work and
  the GPU Compute comparison.
- **Cache & Memory fix.** With kernel same-page merging (KSM) switched on for every program, long
  runs could show impossible memory speeds (over 1,000,000 MB/s). SRS now keeps its benchmark
  memory out of merging before every test. A result faster than the installed memory can deliver
  shows as **not valid** in red.
- The ten "Benchmark: *mode*" tabs are gone from the window. The CPU Benchmarks tab's Mode list runs
  the same modes and shows their last results.
- The tray menu's Exit is now **Quit SRS**.
- Fixes from the pre-release reviews: the benchmark lock never lives in `/tmp`; stopped Crypto and CPU
  Benchmark runs mark what they did not measure; a reused process number is never mistaken for the
  old process; IR Blaster finds the udev rule in `/etc` too and says when the dongle is busy; per-process
  GPU use on more drivers; Alt letters that no longer clash.

Full list in [CHANGELOG.md](CHANGELOG.md).

## Tested on one PC (and what that means)

Tested on one PC (Ryzen 7 7800X3D, RX 9070 XT, ASUS X870, KDE Plasma 6 Wayland). I've done
everything I can for the rest: tests on recorded data, fake devices and stand-in libraries,
careful reading of the docs, and test builds. But I can't try what I don't own. These parts were
**not tried on real hardware** and may have a bug or two I haven't met yet:

- NVIDIA graphics cards (only a stand-in for NVIDIA's library) and Intel GPUs
- other AMD generations (the RX 5000 / 6000 / 7000 PowerPlay tables), APUs (processors with
  built-in graphics), and NPUs (Ryzen AI / XDNA)
- several graphics cards in one PC, laptops and hybrid graphics
- other desktops' trays (GNOME with the AppIndicator extension, XFCE, waybar ...) and the summon
  shortcut
- HiDPI screens and panels
- other IR dongle models: only one OCRUSTAR / ELKSMART `045c:0132` (plain protocol) was used, with
  one TV, where status, probe, send, repeat and learn all worked. The `045c:0184`, `045c:0195` and
  `045c:0134` models are untested.
- the password (pkexec) path of the process actions, other users' processes, Disconnect, and
  Start / Stop / Restart of system services

If you find a bug, please tell me: open an issue on
[GitHub](https://github.com/eugenesflanagin-spec/srs-sysinfo/issues) with your hardware and the
report SRS made, and I'll fix it.

## Upgrading from 2.4.x

Install the new package over the old one; nothing has to be set up again. For the IR Blaster,
install the udev rule (the tab's **Copy Install Command**, or the `elksmart-comm-git` package or
IR Remote), then unplug and replug the dongle.
